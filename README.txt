║     錄音轉會議紀錄 APP（雲端版）— 使用說明      ║
╚══════════════════════════════════════════════╝

【系統需求】
  • 瀏覽器：Google Chrome 或 Microsoft Edge（必須）
  • 網路：首次使用「上傳音檔」功能時需要網路連線
    （下載語音模型約 40MB，之後可離線使用）

【開啟方式】
  1. 雙擊 index.html
  2. 自動以 Chrome 或 Edge 開啟

══════════════════════════════════════════════

【使用流程】

  ① 輸入來源（二選一）

  [直接錄音]
  1. 點擊「開始錄音」
  2. 允許瀏覽器使用麥克風
  3. 開始說話，逐字稿會即時顯示
  4. 說完後點擊「停止錄音」

  [上傳音檔]
  支援格式：mp3、wav、m4a、ogg、webm
  1. 點擊「選擇檔案」，選取錄音檔
  2. 等待辨識完成（進度條顯示進度）
  ★ 首次使用約需等待 1～3 分鐘下載模型

  ② 確認逐字稿
  • 上方輸入「會議名稱」
  • 在文字框中可手動修正辨識錯誤的字（如人名、地名）

  ③ 生成會議紀錄
  • 點擊「生成會議紀錄」按鈕
  • 系統自動填入 8 個章節（壹～捌）
  • 缺少的資訊會以【<<待修正>>】黃色標示，請手動補充

  ④ 下載
  • 下載 Word (.docx)：完整格式文件
  • 下載會議紀錄 (.txt)：純文字版
  • 下載逐字稿 (.txt)：完整逐字稿
  • 下載待辦事項 (.txt)：自動提取的行動清單

══════════════════════════════════════════════

【會議紀錄輸出格式】

  壹、 會議時間
  貳、 會議地點
  參、 主席
  肆、 出席人員（固定顯示「詳如簽到表」）
  伍、 會議報告
  陸、 討論事項（案由一、案由二… 含說明與決議）
  柒、 臨時動議
  捌、 散會

══════════════════════════════════════════════

【注意事項】
  • 錄音辨識需使用中文（台灣）語系
  • 長段錄音建議分段上傳以提升辨識品質
  • 生成的會議紀錄請務必人工確認後再正式使用
  • 所有處理均在本機完成，音訊及文字不會上傳任何伺服器
